# Detector de Movimento Corporal

Site local que usa a camera do navegador para detectar a pose do corpo, comparar os pontos entre frames e mostrar quais partes estao em movimento.

## Como abrir

Execute um servidor local na pasta do projeto e abra o endereco indicado:

```powershell
node server.js
```

Depois acesse:

```text
http://localhost:5173
```

O navegador vai pedir permissao para usar a camera.
